# 拾句 · 英一作文学习室

无模型、无依赖的静态网页。直接打开 index.html，或把整个目录部署为静态网站。手机建议使用固定网站地址，数据按浏览器和网站地址分别保存，不会自动跨设备同步。清除浏览器数据会删除记录，请定期导出 JSON 备份。

## 使用

1. 将题目、自己的作文、范文交给老师分析。
2. 请老师依照 PACK_FORMAT.md 输出 JSON 学习包。
3. 点击「导入学习包」。大作文与小作文独立浏览，可以叠加话题、形式、任务筛选。
4. 进入作文查看原稿、范文、纠错与学习重点，背诵或练习。
5. 在书架点击「复习当前分类」，仅展示当前筛选范围内新卡及到期项目；单篇入口可以随时重练。

「会了」依次在 1、3、7、15 天后复习；「不熟」和「需要问」10 分钟后再出现。练习草稿自动保留。开放改写不自动评分；单答案题忽略首尾空白、连续空格和字母大小写后核对。

## 更新与备份

作文 ID 相同会更新原内容，并先提示确认。稳定的卡片和练习 ID 用来保留进度；学习内容发生实质变化时请换新 ID。备份恢复会合并作文，现有浏览器中同 ID 的进度优先，不会被旧备份覆盖。所有学习内容只进入当前浏览器，不上传 GitHub。

## 文件

- index.html：界面与样式。
- core.js：导入校验、合并、复习算法。
- app.js：交互与教学示例。
- PACK_FORMAT.md：给老师使用的学习包协议。
- test.cjs：运行 `node test.cjs` 检查核心数据逻辑。

示例是自编教学片段，不是完整考场范文，不代表用户原稿。第一版导入文字内容，不嵌入照片。支持电脑与手机响应式布局。

## GitHub

把这些文件放在专用仓库根目录即可。GitHub Pages 如可用，可在仓库 Settings → Pages 中选择从目标分支的根目录发布；应用不需要构建。仓库保存程序代码，学习包和私人学习记录无需提交。
